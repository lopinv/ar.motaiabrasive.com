# 文章系统激活 + AEO/SEO/UEO 增强 + UI 全面升级

## Context

站点当前没有可访问的文章列表页和详情页路由。探索发现：
- `src/content/articles/` 下已有 **2720 篇批量生成的 MDX**（由 `src/templates/topic-matrix.ts` 生成，含 P0-P2 优先级、去重键），frontmatter 完整（13 种 category、产品族/型号/行业/海湾国家交叉、FAQ、infoBoxes、内外链清单、voiceSearchQueries）
- `src/pages/articles/[slug].astro` 详情页**已存在但未激活**（Astro 7 需 `src/content.config.ts`，仓库没有；该文件还有多处 bug 待修）
- **缺失 `/articles` 列表页** → 面包屑死链 + 孤岛判定
- 样式层缺口：`section--light`（13 处使用）与 `section--sand`（3 处）无定义；文章正文样式是 `[slug].astro` 内 178 行私有 style 块，硬编码 9 组非 token 色值

三重目标：①激活文章路由（列表+详情）②产品/服务页与文章互链消除孤岛、提升 AEO 权威度 ③按大型工业 B2B 标准升级 UI 与交互。**不虚构任何认证资质**（无 ISO 就不写 ISO；文章 frontmatter 中的 FEPA/OSHA 等外部标准引用是客观事实，保留）。

## 实施步骤

### 阶段 1：激活文章系统（核心）

1. **新建 `src/content.config.ts`**：glob loader `./articles`，zod schema 沿用 frontmatter 结构（title/description/publishDate/category 枚举/productFamily/productModel/industry/gccCountry/keywords/faq/cta/internalLinks/externalLinks/featuredImage/infoBoxes/voiceSearchQueries 等全部 optional 化处理截断字段，description 不设 min 长度避免构建失败）
2. **安装 `@astrojs/mdx`**（`npm i @astrojs/mdx`，锁定版本）+ `astro.config.mjs` 注册集成
3. **精选发布策略**：只保留去重键相同主题的 `-0` 副本（删除 `-1`+ 后缀重复），再按 `notes` 中 `Priority: P0` → P1 → P2 过滤，目标 **40–60 篇**。剩余移入 `src/content/articles-bank/`（不进 glob，保留资产不删除）
4. **新建 `/articles` 列表页** `src/pages/articles/index.astro`：
   - page-hero + 分类筛选按钮（复用 `.model-filter` JS 过滤模式）+ 文章卡片网格（复用 `.resource-card` 风格改造 `.article-card`：标题、BLUF 摘录、分类徽章、产品族标签、日期）
   - `type="website"`、完整 TDK/OGP/canonical、`BreadcrumbList` + `CollectionPage` JSON-LD
5. **重写 `articles/[slug].astro`**（修复既有 bug）：
   - `set:html={article.body}` → `await render(article)` 正确渲染 MDX
   - 正文样式迁出私有 `<style>`：新建全局 `.article-body` prose 系统（content.css，全用 token：链接用 `--primary`、信息框用 `--brand-100`/`--success-100` 底、`spec-table` 对齐 `.table-wrap`）
   - 页面结构：hero（category 徽章 + H1 + BLUF 直答段——AEO 关键）→ 正文 → frontmatter `faq` 渲染 `<FaqItem>` + **FAQPage JSON-LD**（门禁要求成对）→ 相关产品推荐卡（按 `productFamily` 取 `productCategories` + `models`）→ `internalLinks` 正文上下文链接 → CtaBand
   - Article + FAQPage + BreadcrumbList JSON-LD；外链补 `rel="noopener nofollow"`（当前只有 noreferrer，门禁会 FAIL）
6. **导航接入**：`site.ts` navItems 在「الموارد」前插入 `{ label: 'المقالات', href: '/articles' }`；页脚加列或链接

### 阶段 2：双向关联（消除孤岛 + 权威度）

7. **产品/服务页 ↔ 文章互链**：
   - `products/[slug].astro`、`products/models/[slug].astro`、`industries/[slug].astro`、`resources/[slug].astro` 各加「مقالات ذات صلة」模块：按 productFamily/industry 过滤文章（匹配则列 3 篇卡片链接，无匹配则隐藏），自动满足"每篇文章有站内入链"
   - 首页 `knowledge-hub` 区加 `/articles` 入口；`/resources` 页顶部加文章精选模块
8. **新增强权威内容页**（无虚构资质，用可核验事实）：
   - `/technical-specs`（磨料技术规格中心：FEPA P 粒度对照表全表、单位换算表、基材/结合剂知识——数据来自 glossary + 原站 products.json，客观标准）
   - `/shipping-oem`（中国→海湾物流与 OEM 流程页：交期结构、包装规范、COC/COA 说明——原站文案已有素材）
   - 两页均含 FAQ + FAQPage JSON-LD、面包屑、入链（navItems 或 resources 卡）

### 阶段 3：UI 全面升级（企业级 B2B）

9. **补样式缺口**：`base.css` 定义 `.section--light`（映射 `--band-1`）与 `.section--sand`（映射 `--band-3`），13+3 处使用点立即获得视觉分层
10. **文章阅读体验（强交互）**：
    - 粘性 TOC 目录（文章正文 H2 自动收集，右侧栏 sticky，scrollspy 高亮当前节——IntersectionObserver 复用现有模式）
    - 阅读进度条（页面顶部 2px clay 色条，scroll 监听，reduced-motion 降级）
    - 回到顶部按钮（右下角，滚动 >600px 出现）
11. **列表页交互**：分类筛选（复用 model-filter 即时过滤模式）+ 搜索框（即时过滤标题/关键词）+ 空状态提示
12. **细节打磨**：文章卡片 hover 抬升（对齐 `.cat-card` translateY(-4px)）、`cat-no` 编号节奏、FaqItem 动画微调、focus-ring 圆形按钮适配（修 `base.css:403` 强制 `--r-xs` 问题：圆形按钮 focus 用 `border-radius:50%` 覆写）

### 阶段 4：验证闭环

13. `npm run build` → `npm run check:site`（新页面必须全过：唯一 TDK、description 90-175、单 H1、canonical 一致、OGP 完整、JSON-LD 成对、无孤岛、外链 nofollow、sitemap 收录）
14. 新增文章批量门禁（quality-check.mjs 增强）：文章 description 截断检测（<80 字符 WARN）、同 title 副本检测
15. 浏览器逐页验收：列表页筛选/搜索、详情页 TOC/进度条/FAQ/相关产品、移动端 390px 布局、RTL 混排

## 验收标准

1. `/articles` 列表 + 40-60 篇详情页全部 200 且过三重门禁，0 孤岛 0 断链
2. 每篇文章有 ≥2 个站内入链（列表页 + 对应产品页）；每个产品/行业页有相关文章出口
3. TOC/进度条/筛选/搜索全部可交互且 reduced-motion 降级
4. 全站 UI 无硬编码色值新增（全部走 token），移动端无破版
5. 无任何虚构资质（ISO/SASO 认证声明等）；外部标准引用（FEPA/OSHA）保留为客观知识
